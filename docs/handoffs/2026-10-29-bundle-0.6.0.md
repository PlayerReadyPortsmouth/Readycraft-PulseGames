## Merge resolutions

- All five merged with no textual conflicts. Checked the expected overlaps by reading the result:
  - `core/lobby/GameMenu.java`: #47's Bedrock-form routing and live refresh and #50's Party button
    (opens `PartyMenu`) are both present.
  - `games/quake/QuakeGame.java`: #51's `QuakeLoadoutMenu` in place. This also closes #49's "not done" note about
    the hand-rolled Quake loadout menu.
  - Bedwars: on `core/ui/shop/`; `games/bedwars/shop/ShopLayout.java` deleted (#51).
  - `PulseGamesPlugin`, `GameListener`: #49's listener/watch-menu removals and #51's changes all kept.
  - `config.yml`: `ui.bedrock-forms`, `ui.refresh-ticks` (#47) and `shop.confirm-at` (#49) all present.
- **Hide spectator reactions wired** (#50 left it stored but unused). `SpectatorTools.emote` now plays the
  particle and sound per viewer (`Player.spawnParticle`/`playSound`) instead of one world-wide particle. A viewer
  with `Comfort.HIDE_REACTIONS` on does not see or hear other players' reactions; the sender always sees their own.
  Decision isolated as `SpectatorTools.showsReaction`, covered by `ReactionVisibilityTest`.
  Side effect: players in the same world but outside the game no longer see the reaction particle.
- **Party hint**: Java game-list Party button hint "Click for party help" -> "Click to open your party".
  `partyHelp()` is **kept**: the Bedrock form's Party button (#47, `FormLayout.PARTY`) still calls it, so Bedrock
  players get the chat help rather than the party menu. Worth a follow-up to route Bedrock to `PartyMenu` too.
- Note: there are now three `ShopRules` classes in different packages (`core/economy` from #49, `core/ui/shop`
  from #51, `games/bedwars/shop` existing). They compile and are tested separately; consolidating is a follow-up.
- Version: `pluginVersion` 0.5.0 -> 0.6.0; tracker entry added.

## New config keys

- `ui.bedrock-forms` (default `true`): Bedrock players get forms for the game list, mode picker and confirms.
- `ui.refresh-ticks` (default `40`): how often open game lists and mode pickers update waiting counts.
- `shop.confirm-at` (default `500`): token-shop purchases at or above this price ask first (2x booster always asks).

## What players will notice

- Shops are 54-slot tabbed windows (token shop, Bedwars, ReadyPlayerZ, Quake loadout) with wrapped lore.
- Menu sounds are quieter.
- `/stats` opens a profile menu (`/stats --text` keeps the chat list; `/stats settings` opens settings).
- Bedrock players get forms for the game list and mode picker.
- Party button opens a party menu (Java); new Settings: hide spectator reactions, fewer flashes, Block Party colour patterns.
- Admins: `/pulse maps board` read-only map readiness dashboard.
