## Merge resolutions

- `PulseGamesPlugin`, `StatsService`, `StatsMenu`, `MatchResults`, `config.yml`: both sides kept (additive fields, init, accessors, sections).
- `Commands`: command list is `play party lobby pulse stats shop pulsekits duels results challenges top level wardrobe event ranked`;
  `/pulse reload` reloads lobby placements and events; `/pulse` tab-complete keeps `lobby` and `event`; `/event` and `/ranked` tab-complete both kept.
- `GameMenu`: #61 "My level" and #64 "Ranked Duels" both used slot 52. The bottom row is full (45-47 buttons, 48-50 pager, 51 kit, 53 close),
  so **My level stays at 52 and Ranked Duels moves to top-row slot 6** (right of Quick Play at 4).
- `BotService.difficultyFor`: ranked bot tier first (#64), then the private-match difficulty via `difficultySetting` (#65).
- `InstanceManager` public matchmaking skips practice, ranked and private instances.
- `BotService` target selection: Bedwars decoy/defender foe (#66, when no objectives) and co-op objective target (#67, with objectives) both kept; the branches are exclusive.
- #68 and #66 merged without conflicts.

## Deploy prerequisites

1. **`bedwars-shop.yml`:** the live copy must be replaced with the repo catalogue (or have the `comeback` category and `cb_*` items merged in).
   Without it the comeback forge perk still works but the Comeback shop tab stays hidden.
2. **`cosmetics.yml`** is copied on first run only; nothing to do on a fresh install, but later catalogue changes need a manual copy.
3. **`ranked.season.ends`** is a placeholder `2027-01-31`: confirm the season end date (and `season.id`) before go-live.
4. **`party.max-size: 8`** caps private matches even though `private.max-party` is 16; raise it if larger private matches are wanted.
5. **`lobby.yml`** is new (`plugins/PulseGames/lobby.yml`), created by the `/pulse lobby` commands; NPCs need Citizens.
6. Existing servers keep their own `config.yml`: Bukkit fills missing keys from the jar defaults, but check the new sections
   (`lobby`, `progression`, `events`, `ranked`, `private`, `mercy`, `comeback`) read as expected after the first start.
7. Scheduled events are on by default (`events.enabled: true`, hourly) and announce over PulseNetwork; turn off or adjust the schedule first if that is not wanted on a given server.
8. One-off XP migration: 10 XP per lifetime win on first sight of each player (stored in `engagement.yml` under `levels`).
