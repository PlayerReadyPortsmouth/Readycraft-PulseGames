## Kit API (`core/ui`)

- `Theme`: palette strings (`NAME`, `TEXT`, `GOOD`, `BAD`, `MONEY`, `ACCENT`, `HINT`); `mm(String)` and `plain(Component)`
  return components with italic explicitly off; `title("Games")` gives `Pulse · Games`; `sound(player, Cue)` with
  `Cue.OPEN|CLICK|SUCCESS|ERROR` (quiet, by sound key). `Text.mm` is deliberately untouched (hub controls compare components).
- `Lore`: `of().desc(text)` (wraps at `Lore.WIDTH` = 30, plain text), `line`, `blank`, `kv`, `status`, `hint`, `build()`;
  `Lore.wrap(text, width)`.
- `Buttons`: `item(material, nameMm, Lore|List<Component>)` (hides attribute/extra tooltips), `filler(pane)` (hidden tooltip),
  `glow`, `count(stack, n)` (1-64 stack cue), `head(player, ...)`, `back()`, `close()`, `prev/next/pageIndicator`.
- `Paginator`: `pages(total, per)`, `page(list, per, requested)` with clamping, `Page.hasPrev/hasNext`.
- `Menu`: per-player holder. `set(slot, stack[, action])`, `fillEmpty(pane)`, `back(action)`, `close()`, `pager(page, prev, next)`,
  `renderer(Runnable)`, `refresh()` (re-render in place, only changed slots are written), `open(player)`.
  Nav slots: 27 = Back 18, Close 26; 54 = Back 45, Prev 48, Page 49, Next 50, Close 53.
- `MenuListener`: one listener (registered in `PulseGamesPlugin`). Cancels every click and drag while a `Menu` is the top
  inventory (shift, number key, offhand, double-click, collect-to-cursor included); actions run next tick for the owner, only
  for a click in the menu, only if that menu is still the open window. Never open or close a window inside the click event.

## Behaviour changes

- `GameMenu` is 54 slots: Quick Play top centre (glows), games in a 28-slot grid with paging, stack size = players waiting,
  name shows "N waiting", featured game glows, footer: Party 45, Challenges 46, Top 3 47, Kit 51, Close 53.
- Mode picker is a separate window (27 slots for up to 7 modes, else 54) with Back and per-mode waiting counts.
- Unreleased games (`!gameAvailable`) are hidden from players without `pulsegames.admin` or `features.canary-players`/`features.broad`;
  those players see a grey "(soon)" icon that cannot be played.
- `BedwarsGame.onInventoryDrag` now cancels shop drags (one line, so the shop rework can rebase on it).
- Left for follow-ups: `TokenShopMenu` and `QuakeGame` inline reopens, Bedwars shop, Bedrock forms.
